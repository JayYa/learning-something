# 背景：熟悉 C#，JavaScript 不熟

用户熟悉 C#，JavaScript 用得不熟。C# 背景可以复用：类、接口、泛型、枚举、async/await 这些概念不用从头讲。但要警惕 C# 带来的直觉惯性：TS 的类型在运行时会被擦除（C# 有反射），TS 按结构判断类型兼容（C# 按名字），而且默认情况下类型错误不会阻止产出代码。JS 本身的运行时语义（真值判断、`this`、对象字面量、模块）需要补课。

**Evidence**: 用户自述（2026-11-21）。

**Implications**: 讲新概念时给一个"C# 对照"，同时点明差异在哪；路线中插入第 0.5 阶段"JS 速通"；类、枚举阶段压缩；泛型阶段侧重 TS 独有的部分（类型推断、约束、映射类型），不讲 C# 已有的概念。
